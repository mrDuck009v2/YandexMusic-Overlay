# YM Overlay

Оверлей для Яндекс Музыки в стиле Discord/Steam.

- **Мини-плеер** — маленькая полупрозрачная плашка поверх всех окон (обложка, название, исполнитель, прогресс). Сквозь неё кликается мышь, фокус она не забирает.
- **Панель управления** — открывается по хоткею: обложка, перемотка, пауза/следующий/предыдущий, лайк, shuffle, повтор, громкость, очередь (клик по треку — играть).
- **Текст песни** — отдельное плавающее окно: строки подсвечиваются в такт музыке, клик по строке перематывает к ней. Окно можно перетаскивать за заголовок и менять ему размер за угол (пока открыта панель). Кнопка 📌 **закрепляет** его поверх всех окон (останется на экране и без панели, сквозь него кликается мышь), без закрепления оно видно только при открытой панели. Включить/выключить — кнопка «Текст» в панели. Текущая строка также видна в мини-плеере.
- **Поиск** — вкладка «Поиск» в панели: треки, исполнители, альбомы и плейлисты по категориям. Клик по результату запускает его, ＋ добавляет альбом/плейлист/исполнителя во вкладку «Плейлисты». Музыка при самом поиске не прерывается.
- **Плейлисты** — вкладка «Плейлисты»: свои плейлисты из коллекции Яндекс Музыки и те, что ты добавил в оверлей (по ссылке или кнопкой ＋ из поиска). Клик — запустить, ✕ — убрать из оверлея.
- **Список треков плейлиста** — клик по плейлисту, альбому или исполнителю (во вкладках «Плейлисты» и «Поиск») открывает слева от панели список всех треков: фильтр по названию, клик по треку включает именно его (очередью остаётся сам плейлист), «▶ Играть с начала» включает всё. Когда добавляешь плейлист в оверлей, его список открывается сам. Играющий сейчас трек подсвечивается.
- **Discord** — в профиле показывается «Слушает …» с названием трека, исполнителем, обложкой и полосой времени, как у Spotify (см. раздел «Discord» ниже).
- **Перезапуск Яндекс Музыки** — кнопка «↻ Перезапустить Я.Музыку» в панели (и пункт в трее): заново загружает сайт в скрытом окне. Если при запуске нет интернета, сайт сам пробует загрузиться снова, пока не получится.
- Музыка играет в скрытом окне с сайтом music.yandex.ru, поэтому всё как в браузере: твой аккаунт, подписка, рекомендации.

## Запуск

Нужен Node.js 18+.

```
npm install
npm start
```

При первом запуске откроется окно Яндекс Музыки — войди в аккаунт и запусти любой трек. Дальше окно можно закрыть (оно спрячется, музыка продолжит играть). Логин сохраняется.

## Управление

| Что | Как |
|---|---|
| Панель управления | `Ctrl+Shift+M` (повторно или `Esc` — закрыть) |
| Показать/скрыть мини-плеер | `Ctrl+Shift+H` |
| Закрепить/открепить текст песни | `Ctrl+Shift+L` |
| Поиск, плейлисты, «Моя волна» | кнопка «Открыть Яндекс Музыку» в панели или пункт в трее |
| Автозапуск, выход | меню иконки в трее |

## Внешний вид

Вкладка **«Настройки»** в панели: акцентный цвет, цвет фона и текста (готовые цвета или свой в формате `#rrggbb`), прозрачность мини-плеера, окна текста и панели, размер текста песни, скругление углов, размытие фона. Изменения видны сразу на мини-плеере и окне текста (оно должно быть включено кнопкой «Текст»), сохраняются сами, «Сбросить вид» возвращает стандартные.

## Discord

Работает сам: просто запусти десктопный Discord (в браузерной версии статусы не работают) и включи в нём «Параметры → Приватность активности → Показывать статус активности». Выключить показ можно во вкладке «Настройки» → Discord или в меню трея.

Статус обновляется при смене трека, паузе и перемотке; на паузе он пропадает. Кнопка «Найти в Яндекс Музыке» видна другим людям (тебе самому Discord её не показывает).

**Для того, кто собирает приложение** (один раз): создай «приложение» на <https://discord.com/developers/applications> → **New Application**, назови, например, «Яндекс Музыка» (это название увидят друзья в строке «Слушает …»), скопируй **Application ID** и вставь в константу `DEFAULT_DISCORD_CLIENT_ID` в начале `main.js`. Дальше у всех, кто запускает или устанавливает приложение, ничего вводить не нужно. Свой ID можно задать и вручную во вкладке «Настройки» — он важнее встроенного.

## Настройки

`%APPDATA%\YM Overlay\config.json` (быстро открыть: трей → «Папка с настройками»). Вид (цвета, прозрачность) удобнее менять во вкладке «Настройки», остальное — после правки файла перезапусти приложение.

```
hotkeyPanel, hotkeyHud        — хоткеи
hudCorner                     — top-left | top-right | bottom-left | bottom-right
hudOpacity                    — прозрачность плашки, 0.2…1
theme                         — вид: accent, bg, fg (цвета #rrggbb), lyricsOpacity, panelOpacity,
                                lyricsFontSize, radius, blur (то же, что во вкладке «Настройки»)
hudVisible                    — показывать мини-плеер постоянно
hudFlashOnTrackChange         — если плашка скрыта, показывать её 4 сек при смене трека
discord                       — { enabled, clientId, button }: статус в профиле Discord (удобнее менять во вкладке «Настройки»)
startUrl                      — какую страницу сайта открывать при запуске (по умолчанию music.yandex.ru/collection)
playlists                     — добавленные в оверлей плейлисты (удобнее менять через вкладку «Плейлисты»)
hotkeyLyrics                  — хоткей закрепления текста
lyricsVisible, lyricsPinned   — окно текста включено / закреплено поверх окон
lyricsPos                     — положение и размер окна текста (сбросить: трей → «Вернуть окно текста на место»)
hudLyrics                     — показывать текущую строку песни в мини-плеере (true/false)
lyricsOffset                  — сдвиг текста в секундах: + строки раньше, − позже (например, -0.5)
```

## Установщик (.exe)

```
npm run dist
```

Готовый установщик появится в папке `dist/`. Пункт «Запускать вместе с Windows» работает именно из установленной версии.

## Ограничения

- Тексты берутся из открытой базы [LRCLIB](https://lrclib.net), а не с Яндекса: для части треков (особенно русских и новых) синхронного текста нет — тогда показывается обычный текст без подсветки, а если нет и его — «не найден». Для этого нужен доступ в интернет к lrclib.net.
- Поиск, список плейлистов и запуск по ссылке работают через скрытое окно с сайтом: оно открывает страницы поиска/коллекции и читает адреса ссылок на них. Если Яндекс сильно поменяет сайт, это может перестать работать (в трее есть «Отладка: данные о поиске» и «Отладка: данные о плейлистах»).
- Список треков читается со страницы плейлиста (она подгружается по мере прокрутки, поэтому у длинных плейлистов чтение занимает до 20 секунд, максимум 500 треков). Если сайт под списком показывает рекомендации, они могут попасть в конец списка.
- Обложка в Discord берётся напрямую с серверов Яндекса; если Discord её не показал — это ограничение Discord, статус при этом работает.
- Запуск альбома, плейлиста или исполнителя из оверлея открывает его страницу в скрытом окне и нажимает «слушать», поэтому предыдущий трек прерывается, а старт занимает пару секунд.

- Игры в эксклюзивном полноэкранном режиме перекрывают любые оверлеи. В «оконном без рамки» всё работает.
- Приложение управляет плеером через внутренний `window.externalAPI` сайта. Он не документирован официально, поэтому если Яндекс его изменит, часть кнопок (лайк, shuffle, повтор, очередь) может перестать работать.
