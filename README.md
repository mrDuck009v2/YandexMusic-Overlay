# YM Overlay

Оверлей для Яндекс Музыки в стиле Discord/Steam.

- **Мини-плеер** — маленькая полупрозрачная плашка поверх всех окон (обложка, название, исполнитель, прогресс). Сквозь неё кликается мышь, фокус она не забирает.
- **Панель управления** — открывается по хоткею: обложка, перемотка, пауза/следующий/предыдущий, лайк, shuffle, повтор, громкость, очередь (клик по треку — играть).
- Музыка играет в скрытом окне с сайтом music.yandex.ru, поэтому всё как в браузере: твой аккаунт, подписка, рекомендации.

## Запуск

Нужен Node.js 18+.

```
npm install
npm start
```

При первом запуске откроется окно Яндекс Музыки — войди в аккаунт и запусти любой трек. Дальше окно можно закрыть (оно спрячется, музыка продолжит играть). Логин сохраняется.

## Управление

| Что | Как |
|---|---|
| Панель управления | `Ctrl+Shift+M` (повторно или `Esc` — закрыть) |
| Показать/скрыть мини-плеер | `Ctrl+Shift+H` |
| Поиск, плейлисты, «Моя волна» | кнопка «Открыть Яндекс Музыку» в панели или пункт в трее |
| Автозапуск, выход | меню иконки в трее |

## Настройки

`%APPDATA%\YM Overlay\config.json` (быстро открыть: трей → «Папка с настройками»). После правки перезапусти приложение.

```
hotkeyPanel, hotkeyHud        — хоткеи
hudCorner                     — top-left | top-right | bottom-left | bottom-right
hudOpacity                    — прозрачность плашки, 0.2…1
hudVisible                    — показывать мини-плеер постоянно
hudFlashOnTrackChange         — если плашка скрыта, показывать её 4 сек при смене трека
```

## Установщик (.exe)

```
npm run dist
```

Готовый установщик появится в папке `dist/`. Пункт «Запускать вместе с Windows» работает именно из установленной версии.

## Ограничения

- Игры в эксклюзивном полноэкранном режиме перекрывают любые оверлеи. В «оконном без рамки» всё работает.
- Приложение управляет плеером через внутренний `window.externalAPI` сайта. Он не документирован официально, поэтому если Яндекс его изменит, часть кнопок (лайк, shuffle, повтор, очередь) может перестать работать.
